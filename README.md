# apk-reverse

An Agent Skill for Android APK reverse engineering.

本仓库是个人学习用途的分支，用于研究 Android 应用分析方法与工具使用，不面向公众提供使用。

## 说明

- 仓库内容是一套方法与脚本，不附带任何样本、目标数据或第三方二进制。
- 仅供学习、研究与**经授权**的安全测试（自有应用、公开 CTF 材料、自控沙箱）。
- 按「现状」提供，不附带任何形式担保；使用产生的一切后果由使用者自行承担。
- 与任何应用、厂商或平台均无隶属或背书关系；相关名称归各自所有者。

完整结构与用法见 `skills/apk-reverse/SKILL.md`。
